# Entity Network — Part 7

## Federal nodes

- **White House / NSC:** sets whole-of-government objectives; historically separates overt and covert authorities.
- **State Department:** diplomacy, recognition, sanctions policy, political strategy, stabilization lead, DRL and INL awards.
- **USAID / OTI:** finance, rapid transition programs, local access, governance, media, civil society, service delivery, implementer oversight.
- **DOD / SOF:** military capability, equipment, security support, logistics, stabilization support.
- **CIA / intelligence community:** covert action where authorized, collection, liaison, partner-service and security relationships.
- **DOJ / FBI / DEA:** justice/police operations, expertise, counternarcotics and information relationships.
- **Treasury:** sanctions and financial pressure.

## Intermediary nodes

- **NED / IRI / NDI / IFES / CEPPS:** election, party, polling, civic, youth, and political-process networks.
- **Contractors:** Creative Associates, DynCorp/PAE/Amentum, Chemonics, and country-specific implementers.
- **Media / anti-corruption networks:** OCCRP, ICFJ, independent outlets, fact-checking and information-resilience organizations.
- **Foundations / fiscal sponsors:** historical CIA pass-through foundations; modern foundations and Tides require transaction-specific analysis.
- **International bodies:** IMF, World Bank, IDB, EU, UN, OAS, and Core Group formations.

## Country clusters

- **Syria:** State + USAID + DOD → START/SSAP → councils/media/services/security; CIA + partner states → vetted armed opposition.
- **Ukraine:** USAID/State/NED/CEPPS → civil society/parties/media/elections; later DOD/intelligence → security capacity.
- **Venezuela:** State/Treasury/USAID → recognition + sanctions + aid + transition plan → opposition/negotiated transition.
- **Haiti:** Core Group diplomacy + governance/police portfolios → succession leverage after an independently caused assassination.
- **Bangladesh:** democracy implementers + embassy pressure + durable elite relationships → influence environment; event bridge unresolved.
- **OCCRP:** State/USAID grants → independent transnational newsroom/data infrastructure → investigations → possible official/civic action.

## Boundary conditions

Funding does not equal control. Coordination does not equal covert action. Independent recipients may still be useful to strategy. A complete edge requires an award, role assignment, tasking record, shared operational process, or sufficiently independent convergence.
