# Independent quality gates

Record evidence for every status. Missing or subjective reviews remain NOT RUN or NEEDS
REVIEW. Software may compute Gate A but cannot assign Gate G.

| Gate | Status | Evidence / reviewer finding |
| --- | --- | --- |
| A | NOT RUN | Technical validation not yet run. |
| B | NOT RUN | Research completeness review not yet run. |
| C | NOT RUN | Thesis-fidelity review not yet run. |
| D | NOT RUN | Narrative review not yet run. |
| E | NOT RUN | Gold/voice and semantic anti-AI review not yet run. |
| F | NOT RUN | Independent evidence-integrity review not yet run. |
| G | AUTHOR APPROVAL REQUIRED | Only the author may approve publication. |

Allowed statuses: PASS, FAIL, NEEDS REVIEW, BLOCKED, NOT RUN, AUTHOR APPROVAL REQUIRED.
